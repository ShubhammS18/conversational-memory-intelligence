## Canonical human quiz · 2026-09-08

- State: in progress; Question 1 passed and Question 2 issued.
- Question 1 · design decision: Why does current-state retrieval use one
  validated trusted UTC clock value for expiration, allowlisting, and
  hydration, instead of reading the clock separately or using caller event
  timestamps?
- Human answer: one trusted UTC time keeps the complete retrieval consistent so
  a memory cannot expire in one step but remain allowed in another because time
  advanced. Caller event timestamps are unsuitable for lifecycle decisions
  because they may be wrong, stale, or manipulated.
- Assessment: `PASS`; the answer correctly explains single-snapshot consistency
  and the separation of trusted lifecycle time from untrusted provenance time.
- Question 2 · edge case: What must happen when trusted `now` is exactly a
  memory's `valid_until`, and what must retrieval do if the atomic SQLite
  expiration transition fails?
- Human answer: at exact `valid_until`, the memory must be marked expired and
  excluded from current retrieval. If the transition fails, retrieval must stop
  and fail closed without embedding, FAISS search, or returning a possibly
  expired memory.
- Assessment: `PASS`; the answer correctly states the inclusive expiration
  boundary and the required pre-search fail-closed behavior.
- Question 3 · change impact: After a memory is persisted as `EXPIRED`, how do
  current and explicit historical retrieval treat it, and which stored data
  must the expiration transition leave unchanged?
- Human answer: current retrieval excludes it. Explicit history may return it
  only when owner-scoped, indexed, non-deleted, and not linked as superseded.
  Expiration changes only lifecycle status and preserves content, ownership,
  relationships, vector mapping, and the FAISS generation.
- Assessment: `PASS`; the answer correctly distinguishes current and explicit
  historical behavior and identifies the lifecycle-only mutation boundary.
- Final result: `PASS 3/3`.
- State: independent L4 and the canonical human quiz are complete; M6 is
  eligible for explicit closure authorization but remains open.
