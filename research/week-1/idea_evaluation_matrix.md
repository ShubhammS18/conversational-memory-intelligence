# Idea Evaluation Matrix

This matrix records the ideas selected for deeper validation during Week 1 and evaluates whether they should be incorporated into the baseline conversational memory system.

| Idea | Source | Component | Failure mode addressed | Current approach | Proposed change | Expected benefit | Integration cost | Latency / Cost / Privacy Risk | Smallest validating experiment | Decision |
|------|--------|-----------|------------------------|-----------------|----------------|-----------------|-----------------|------------------------------|-------------------------------|----------|
| Lightweight temporal metadata for conflict resolution | Zep: A Temporal Knowledge Graph Architecture for Agent Memory (2025) | Ranking & Conflict Resolution | Older memories continue competing with newer ones because semantic similarity alone cannot determine which memory is currently valid. | Memories are retrieved mainly using semantic similarity and metadata. | Store lightweight temporal status metadata with each memory and use it during ranking to identify superseded memories. Do not introduce a full knowledge graph. | More reliable handling of updated or conflicting memories while keeping the architecture simple. | Low-Medium | Slight increase in metadata storage and ranking logic. No significant latency impact expected. | Create two memories describing the same preference at different times and verify that the latest valid memory is consistently selected during retrieval. | Prototype |
| Multi-signal admission policy | Adaptive Memory Admission Control (A-MAC), Zhang et al. (2026) | Memory Extraction & Admission | The admission stage exists, but there is no well-defined policy for deciding which extracted memories should be stored as long-term memory. | Candidate memories are extracted, checked for confidence and duplicates, and then evaluated for admission before storage. | Replace simple admission rules with a structured multi-signal admission policy that considers utility, confidence, novelty, recency and memory type before storing a memory. | More consistent admission decisions, fewer duplicate or low-value memories, and higher-quality long-term memory. | Medium | One additional LLM call for utility scoring increases cost slightly, while the remaining signals are lightweight. | Compare memory quality before and after introducing the multi-signal admission policy using conversations containing both useful and trivial information. | Adopt |
| Evidence-informed lifecycle policies | When to Forget: A Memory Governance Primitive (2026) | Reflection & Lifecycle | Reflection and consolidation exist, but there is no clear policy for deciding when stored memories should be updated, retired or forgotten. | Memories are periodically consolidated through reflection, but lifecycle decisions rely on static rules rather than evidence gathered over time. | Extend the lifecycle component by introducing evidence-informed review of stored memories. The complete Memory Worth mechanism will not be part of the baseline implementation. | More principled lifecycle management and a clearer strategy for handling obsolete or low-value memories as the memory store grows. | Medium-High | Requires monitoring memory usage and retrieval outcomes, which increases implementation complexity beyond the baseline. | Simulate long-running conversations and evaluate whether evidence-informed reflection can identify obsolete or superseded memories for review. | Prototype |
